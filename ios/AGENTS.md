# ios/

## Purpose
Native iOS/Xcode project scaffolding generated by **Capacitor** (`npx cap sync ios`, driven by `capacitor.config.json` at the repo root: `appId: com.freeley.app`, `appName: Freeley`, `webDir: www`). It wraps the site's built web output (`www/`, produced by `npm run build:mobile`) in a WKWebView-based native shell for the App Store. Standard Xcode project layout (`App.xcodeproj`, Swift Package Manager wrapper) — most of it is regenerated by Capacitor tooling, not hand-authored.

## For AI Agents
### Working In This Directory
- **Do not hand-edit generated asset catalogs or storyboard resources** (`ios/App/App/Assets.xcassets`, `ios/App/App/Base.lproj`) unless intentionally rebranding app icons/launch screens — prefer regenerating via `@capacitor/assets` / `npx cap sync ios` where possible.
- **Do not create AGENTS.md files anywhere inside this directory** — this single file documents the whole `ios/` tree.
- Real, intentional customization (not auto-regenerated) lives in a small number of files:
  - `ios/App/App/AppDelegate.swift` — the app's native entry point/lifecycle hooks; this is where native plugin setup or custom native code would go.
  - `ios/App/App/Info.plist` — app permissions (camera, push notifications, etc.), bundle identifier, display name.
  - `ios/App/App.xcodeproj` — Xcode project/build settings (signing team, capabilities like Push Notifications must be enabled here in Xcode, not by editing project files by hand).
  - `ios/App/CapApp-SPM/Package.swift` — Swift Package Manager manifest wiring in the Capacitor plugins (`@capacitor/camera`, `@capacitor/push-notifications`, etc., mirrored from `package.json`).
  - `ios/debug.xcconfig` — build configuration overrides for debug builds.
- Capacitor plugins in use (from `package.json`): `@capacitor/ios`, `@capacitor/camera`, `@capacitor/push-notifications` — changes to plugin config belong in `capacitor.config.json` at the repo root, then re-synced here.
- To rebuild this directory from source: `npm run build:mobile` (rsyncs the repo into `www/`) then `npx cap sync`.
