# android/

## Purpose
Native Android project scaffolding generated by **Capacitor** (`npx cap sync android`, driven by `capacitor.config.json` at the repo root: `appId: com.freeley.app`, `appName: Freeley`, `webDir: www`). It wraps the site's built web output (`www/`, produced by `npm run build:mobile`) in a WebView-based native shell so it can ship to the Play Store. This is standard Gradle/Java/XML Android project structure, many directories deep — most of it is regenerated by Capacitor tooling, not hand-authored.

## For AI Agents
### Working In This Directory
- **Do not hand-edit generated resource/drawable/mipmap folders** (`app/src/main/res/**`, icons, splash screens) — these are overwritten by `npx cap sync android` / `@capacitor/assets`. Regenerate them through the Capacitor tooling instead of editing XML/PNGs directly.
- **Do not create AGENTS.md files anywhere inside this directory** — this single file documents the whole `android/` tree.
- Real, intentional customization (not auto-regenerated) lives in a small number of files:
  - `app/src/main/AndroidManifest.xml` — app permissions, activity declarations.
  - `app/src/main/java/com/freeley/app/MainActivity.java` — the app's native entry point (Capacitor's `BridgeActivity` subclass); this is where native plugin registration or custom native code would go.
  - `app/build.gradle` — `applicationId "com.freeley.app"`, version code/name, dependencies (`@capacitor/*` plugins declared in `package.json` sync here).
  - `variables.gradle`, `build.gradle` (project root), `gradle.properties`, `capacitor.settings.gradle` — build-wide config, largely templated by Capacitor and rarely needs manual edits.
- Capacitor plugins in use (from `package.json`): `@capacitor/android`, `@capacitor/camera`, `@capacitor/push-notifications` — changes to plugin config belong in `capacitor.config.json` at the repo root, then re-synced here, not edited directly in the generated Gradle files where avoidable.
- To rebuild this directory from source: `npm run build:mobile` (rsyncs the repo into `www/`, excluding `.git`, `node_modules`, `.venv`, `ios`, `android` itself) then `npx cap sync`.

### Testing Requirements
No automated tests target this directory. Verification is manual: build/run via Android Studio or `./gradlew assembleDebug` and check the app launches and loads `www/` correctly.
