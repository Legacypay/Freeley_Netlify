# public/assets/

## Purpose
Large themed tree of static image (and a handful of video/script) assets, consumed by both the live Astro vertical pages (`../../src/pages/*.astro`) and the legacy standalone `.html` pages one level up in `public/`. Each top-level subdirectory is scoped to one page or one of the site's four verticals — hair loss (`hl/`), sexual wellness (`sw/`), weight loss (`wl/`), longevity (`l/`) — plus a few shared/cross-vertical folders (`brand/`, `brands/`, `home/`, `lifestyle/`). This file covers only the tree shape and the one non-image subdirectory (`js/`); the image-only subdirectories themselves do **not** get their own `AGENTS.md` — treat directory names and the mapping below as the map.

## For AI Agents
### Working In This Directory
- Before adding or renaming a file, check which page(s) reference the containing subdirectory using the mapping above, then grep to confirm (`grep -rl "assets/<dir>/" ../../src ../*.html`).
- The four `js/*-script.js` files are near-duplicates of each other (same gallery/carousel/Tawk.to pattern, one per vertical) — when fixing a bug in one, check whether the same bug exists in the other three.
- Product-image comments inside the `js/*-script.js` files call out real content bugs already found and fixed (e.g. showing a competitor SKU's own labeled bottle to the wrong shopper) — read the inline comments before reordering an `images: [...]` array.

### Testing Requirements
No automated tests. Verify an image/video path resolves by checking the corresponding page in `npm run build` output (`dist/assets/...`) or `netlify dev`.

### Common Patterns
- Astro pages reference these assets with a leading-slash absolute path: `/assets/hl/product1.png`, `/assets/js/wl-script.js`.
- Product-gallery data (name/price/features/image list) lives inline as a JS object literal at the top of each `js/*-script.js` file — that's the place to edit copy or swap product photos, not the `.astro` markup.

## Dependencies
### Internal
- `../../src/pages/*.astro` (each vertical page pulls its own subdirectory + its own `js/*-script.js`)
- `../style/quizstyle.css` (background-image reference into `quiz/`)
- `../../content/blog/*.md` (source of the `blog/` article images' subject matter)
- `../../generate-og-images.js`, `../../seo.js`, `../../generate-runway-videos.js`, `../../generate-sora-videos.js` (repo-root generation scripts that populate `og/` and `videos/`)

### External
- Tawk.to (live chat widget, injected by all 4 `js/*-script.js` files) and Swiper (carousel library, instantiated by the same files but loaded from elsewhere — not vendored in this directory).
